# QA Grading System

Веб-приложение для оценки компетенций QA-команды, расчёта грейдов и премий.
Интерактивная реализация методики грейдирования (матрица компетенций + цели + премирование).

---

## Возможности

- **Дашборд** — средний % грейда команды, фонд премий, распределение по грейдам, график премий.
- **Команда** — сводная таблица + история оценок по кварталам.
- **Оценки** — баллы 1–5 по 19 компетенциям с учётом весов и категорий.
- **Цели** — добавление целей, привязка к бизнес-целям, автоматическая оценка A–E.
- **Премия** — живой калькулятор: меняешь оклад / % / коэффициент — премия пересчитывается сразу.
- **Экспорт** — выгрузка состояния в `QA_System.xlsx`.

## Логика расчёта

```
ГРЕЙД  ← пороги по % компетенций
ОЦЕНКА ← выполнение целей (A–E)
ПРЕМИЯ = оклад × % премии(грейд) × коэффициент(оценка)
```

| Оценка | Условие | Коэф. премии |
|---|---|---|
| A | цель перевыполнена (>100%) | 1.2 |
| B | цель выполнена (100%) | 1.0 |
| C | частично (<100%) | 0.6 |
| D / E | не выполнено | 0.0 |

| Грейд | Порог % | Доля премии |
|---|---|---|
| Джун 1 | 50 | 0% |
| Джун 2 | 65 | 10% |
| Мидл 3 | 75 | 15% |
| Мидл 4 | 82 | 20% |
| Сеньор 5 | 90 | 25% |
| Сеньор 6 | 96 | 30% |

## Запуск

```bash
python3.12 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py                      # → http://localhost:8080
```

## Стек

`Python 3.12` · `NiceGUI` · `pandas` · `openpyxl`
